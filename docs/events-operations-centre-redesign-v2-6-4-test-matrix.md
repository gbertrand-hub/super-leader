# Matrice de tests V2.6.4

## Navigation generale

1. Ouvrir `/dashboard/events`.
2. Verifier que le formulaire de creation n'occupe plus la colonne gauche.
3. Cliquer sur `+ Creer un evenement` puis fermer le formulaire.
4. Changer d'evenement avec le selecteur.

## Banniere et indicateurs

1. Verifier le nom, le statut, les dates, le lieu et le responsable.
2. Verifier les compteurs Equipe, Taches, Progression et Budget.
3. Verifier qu'un evenement futur en `planning` n'est pas compte comme `En cours`.

## Onglets

1. Ouvrir successivement Vue d'ensemble, Equipe, Taches, Planning, Budget, Documents et Rapport final.
2. Actualiser chaque onglet et verifier que l'onglet reste selectionne.
3. Soumettre un formulaire dans chaque onglet et verifier le retour dans le meme onglet.

## Actions rapides

1. Cliquer sur Ajouter un membre.
2. Cliquer sur Creer une tache.
3. Cliquer sur Ajouter une activite.
4. Cliquer sur Ajouter un document.
5. Verifier que la rubrique et le formulaire correspondants sont ouverts.

## Vue d'ensemble

1. Verifier la prochaine echeance.
2. Verifier les taches critiques et les risques.
3. Verifier la prochaine activite.
4. Verifier les membres sans tache.
5. Verifier les documents recents.
6. Ouvrir et enregistrer la modification de l'evenement.

## Budget

1. Verifier le budget previsionnel.
2. Verifier la somme des budgets de taches.
3. Verifier les couts reels et le solde.
4. Modifier le budget et verifier que les autres donnees de l'evenement restent intactes.

## Permissions

1. Owner/Admin/RH ou responsable autorise : tous les onglets de gestion.
2. Membre de mission : consultation des rubriques autorisees.
3. Responsable d'une tache : mise a jour de sa propre tache uniquement.
4. Collaborateur non affecte : evenement non visible.
