# Performance V1.1 — Gouvernance des rapports journaliers

## Règle centrale

Après l’heure limite configurée, le rapport du jour est verrouillé. Un collaborateur ne peut plus remplir une journée passée ou fermée sans autorisation exceptionnelle.

## Pouvoirs du superviseur

Le superviseur affecté peut :

1. réouvrir une date précise pendant une durée limitée ;
2. indiquer si le motif est exceptionnel et justifié ;
3. compléter le rapport au nom du collaborateur ;
4. révoquer une autorisation encore active ;
5. valider ou demander la correction du rapport.

Les propriétaires, administrateurs et RH conservent un droit de contrôle global.

## Traçabilité

Chaque action enregistre :

- l’auteur réel ;
- le collaborateur concerné ;
- la date du rapport ;
- le motif ;
- la durée de réouverture ;
- le pourcentage de points attribué ;
- l’heure exacte de l’action.

Un rapport complété par le superviseur ne peut pas être présenté comme ayant été rempli par le collaborateur.

## Barème par défaut

- rapport normal soumis à l’heure : 100 % ;
- réouverture exceptionnelle justifiée : 100 % ;
- réouverture non exceptionnelle : 70 % ;
- rapport complété par le superviseur : 50 % ;
- rapport non soumis : 0 %.

Ces valeurs sont configurables dans les paramètres Performance.
