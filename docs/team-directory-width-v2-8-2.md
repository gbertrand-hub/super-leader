# Super Leader V2.8.2 — Team Directory Width Hotfix

This hotfix widens the left-hand team directory on desktop screens while preserving the two-pane workspace.

## Changes

- Desktop directory width increased from roughly 320 px to a responsive 390–440 px.
- Team names, departments, manager names, member counts and filters have more usable space.
- Horizontal overflow is hidden inside the directory to remove the unnecessary bottom scrollbar.
- Vertical scrolling remains independent from the team details panel.
- No Supabase migration is required.
